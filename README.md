# DEMO - Luxury Fine Dining Restaurant Website

A royal, high-end fine dining restaurant website featuring an obsidian dark theme, liquid gold shimmer typography, multi-layered button animations, and interactive dining modules.

---

## 🌟 Highlights & Features

- **Royal Gold Typography & Text Shimmer:**
  - Dynamic linear gradients mimicking metallic 24K gold foil.
  - Animated gold shimmer text effects on headings and logos (`Cinzel` & `Playfair Display`).
- **Captivating Button Animations:**
  - **Liquid Gold Light Beam Sweep (`.btn-shimmer`):** Gliding 45-degree light flare across buttons.
  - **Pulsing Golden Aura Glow (`.btn-animated-glow`):** Subtle breathing radial glow around interactive elements.
  - **Expand Fill Hover (`.btn-outline-gold`):** Outline shifts into solid gold with elevation on hover.
  - **Micro-interactions:** Interactive cart addition confirmations with checkmark feedback.
- **Interactive Modules:**
  - **Table Reservation System:** Complete with date/time pickers, seating area pills, and instant royal voucher confirmation modal accompanied by a custom 24K gold confetti explosion canvas.
  - **Interactive Dining Tray (Cart Drawer):** Add dishes, adjust portions, and see dynamic subtotal, gratuity, and total calculation.
  - **Menu Category Filter:** Starters, Prime Mains, 24K Gold Cuts, Confections, and Vintage Elixirs.
  - **Hero Animated Metrics:** Dynamic counting animation for Michelin stars, dishes, and satisfaction metrics.
  - **Responsive Navigation:** Glassmorphism sticky header and slide-in mobile navigation drawer.

## 🚀 How to View & Run

1. Simply double-click `index.html` to open it in any web browser (Google Chrome, Microsoft Edge, Firefox, Safari).
2. Or serve it using any local static server (e.g. `npx serve`, VS Code Live Server, or Python `python -m http.server 3000`).
